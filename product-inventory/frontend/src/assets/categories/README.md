# Category images

The product grid shows one image per category. File name = category name in lower case,
spaces and symbols replaced by `-`.

| Category        | Put your image here                  |
|-----------------|--------------------------------------|
| Electronics     | `electronics.jpg`                    |
| Furniture       | `furniture.jpg`                      |
| Stationery      | `stationery.jpg`                     |
| Accessories     | `accessories.jpg`                    |
| Home Appliances | `home-appliances.jpg`                |

Supported formats, tried in this order: `.jpg`, `.png`, `.webp`, `.svg`.
If none exists, `default.svg` is shown. The `.svg` files here are placeholders;
add a `.jpg` (or `.png` / `.webp`) with the same name to replace one.
Recommended size: 800 x 600 px (4:3).
